## ✨ Sobre o Projeto

**Tools** é um repositório que reúne diversas ferramentas desenvolvidas para auxiliar em atividades de:

* 🔎 Reconhecimento (Recon)
* 🌐 Enumeração de ativos
* 📂 Descoberta de diretórios
* 🧭 Análise DNS
* ⚡ Automação de tarefas
* 🛡️ Segurança Ofensiva
* 📚 Estudos e Laboratórios

O objetivo é centralizar scripts e utilitários criados durante estudos, projetos e práticas de Pentest, Red Team e Segurança da Informação.

---

## 📦 Ferramentas Disponíveis

### 🛰️ DNS Sweeper

Ferramenta de enumeração DNS desenvolvida em Bash.

**Recursos:**

* IPv4 (A)
* IPv6 (AAAA)
* Name Servers (NS)
* Mail Servers (MX)
* SPF Records
* Zone Transfer
* Subdomain Bruteforce

📁 Localização:

```text
Tools/
└── DNS_Sweeper/
```

---

### 📂 Directory Finder

Ferramenta de Directory Bruteforce desenvolvida em Python.

**Recursos:**

* Enumeração de diretórios web
* Suporte a HTTPS
* Wordlists personalizadas
* Detecção de respostas HTTP 200

📁 Localização:

```text
Tools/
└── Directory_Finder/
```

## 🚀 Instalação

Clone o repositório:

```bash
git clone https://github.com/Douglas-fCruz/Tools.git

cd Tools
```

Acesse a ferramenta desejada:

```bash
cd DNS_Sweeper
```

ou

```bash
cd Directory_Finder
```

Consulte o README específico de cada ferramenta para instruções detalhadas de instalação e uso.
